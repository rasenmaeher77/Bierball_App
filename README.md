# Bierball Regelwerk

Leere, für das iPhone optimierte Web-App-Vorlage (HTML, CSS, JavaScript, keine Frameworks).

| Datei / Ordner         | Zweck                                             |
|------------------------|---------------------------------------------------|
| `index.html`           | Inhalt der App (`<main class="app">` ist leer)    |
| `css/style.css`        | Grundstil, Safe-Areas, Dark Mode                  |
| `js/app.js`            | Service Worker, Regelwerk + Inhaltsverzeichnis    |
| `js/markdown.js`       | Wandelt den Regelwerk-Text in HTML um             |
| `Regelwerk/`           | Regelwerk-Text (`regelwerk.js`), Grafik, PDF      |
| `manifest.webmanifest` | Name, Icon und Farben auf dem Home-Bildschirm     |
| `sw.js`                | Service Worker; neue Dateien in `FILES` eintragen |
| `icons/`               | App-Icons (180, 192, 512 px)                      |
